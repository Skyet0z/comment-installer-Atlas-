Pour installer les saisons Fortnite (pour rappel de la Saions 01 chapitre 1 à la version 30.00 qui est celle de Fortnite OG originel), veuillez suivre ce lien:
https://fortforge.co.uk/builds

une fois que vous êtes sur le site, choisissez la version que vous voulez installer (⚠️ veuillez prendre en compte que les versions téléchargés sont en .zip/.rar et donc prévoir de l'espace disque supplémentaires)
